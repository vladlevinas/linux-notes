# pct clone

> Clone a container.
> More information: <https://pve.proxmox.com/pve-docs/pct.1.html>.

- Clone a container:

`pct clone {{template_id}} {{copy_id}}`

- Clone a container with a custom name:

`pct {{[cl|clone]}} {{template_id}} {{copy_id}} --hostname {{host_name}}`
